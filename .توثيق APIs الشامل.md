## 🚀 مقدمة

### معلومات عامة
- **Base URL**: `http://localhost:5000/api`
- **Protocol**: HTTP/HTTPS
- **Data Format**: JSON
- **Authentication**: JWT Bearer Token
- **Rate Limiting**: 1000 requests/hour per user

### Headers مطلوبة
```http
Content-Type: application/json
Authorization: Bearer <jwt_token>
Accept: application/json
```

### Response Format
جميع الاستجابات تتبع التنسيق التالي:
```json
{
  "success": true|false,
  "data": {},
  "message": "string",
  "timestamp": "ISO 8601 datetime",
  "errors": []
}
```

## 🔐 المصادقة والتفويض

### تسجيل الدخول
**POST** `/auth/login`

تسجيل الدخول والحصول على JWT token.

#### Request Body
```json
{
  "username": "string",
  "password": "string",
  "remember_me": false
}
```

#### Response
```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh_token": "refresh_token_here",
    "expires_in": 3600,
    "user": {
      "id": 1,
      "username": "admin",
      "email": "admin@example.com",
      "role": "admin",
      "last_login": "2025-07-28T16:30:00Z"
    }
  },
  "message": "تم تسجيل الدخول بنجاح"
}
```

#### Error Response
```json
{
  "success": false,
  "message": "اسم المستخدم أو كلمة المرور غير صحيحة",
  "errors": ["INVALID_CREDENTIALS"]
}
```

### تجديد الرمز المميز
**POST** `/auth/refresh`

تجديد JWT token باستخدام refresh token.

#### Request Body
```json
{
  "refresh_token": "refresh_token_here"
}
```

#### Response
```json
{
  "success": true,
  "data": {
    "token": "new_jwt_token",
    "expires_in": 3600
  }
}
```

### التحقق من الرمز
**GET** `/auth/verify`

التحقق من صحة JWT token.

#### Headers
```http
Authorization: Bearer <jwt_token>
```

#### Response
```json
{
  "success": true,
  "data": {
    "valid": true,
    "user_id": 1,
    "username": "admin",
    "role": "admin",
    "expires_at": "2025-07-28T17:30:00Z"
  }
}
```

### تسجيل الخروج
**POST** `/auth/logout`

إلغاء صحة الرمز المميز وتسجيل الخروج.

#### Response
```json
{
  "success": true,
  "message": "تم تسجيل الخروج بنجاح"
}
```

## 📊 البيانات والمحتوى

### التسجيلات الصوتية

#### قائمة التسجيلات
**GET** `/recordings/audio`

الحصول على قائمة التسجيلات الصوتية.

#### Query Parameters
- `device_id` (optional): تصفية حسب الجهاز
- `start_date` (optional): تاريخ البداية (ISO 8601)
- `end_date` (optional): تاريخ النهاية (ISO 8601)
- `duration_min` (optional): الحد الأدنى للمدة (ثواني)
- `duration_max` (optional): الحد الأقصى للمدة (ثواني)

#### Response
```json
{
  "success": true,
  "data": {
    "recordings": [
      {
        "id": 1,
        "device_id": "device_001",
        "filename": "recording_20250728_163000.mp3",
        "duration": 120,
        "file_size": 2048576,
        "quality": "high",
        "format": "mp3",
        "recorded_at": "2025-07-28T16:30:00Z",
        "download_url": "/api/recordings/audio/1/download",
        "waveform_url": "/api/recordings/audio/1/waveform"
      }
    ],
    "total_duration": 7200,
    "total_size": "45.2 MB"
  }
}
```

تحميل ملف التسجيل الصوتي.

## 🔌 WebSocket APIs

### الاتصال
```javascript
const socket = io('ws://localhost:5000', {
  auth: {
    token: 'jwt_token_here'
  }
});
```

### الأحداث المتاحة

#### device_connected
```javascript
socket.on('device_connected', (data) => {
  console.log('جهاز متصل:', data);
  // data: { device_id, device_name, timestamp }
});
```

#### device_disconnected
```javascript
socket.on('device_disconnected', (data) => {
  console.log('جهاز منقطع:', data);
  // data: { device_id, device_name, timestamp }
});
```

#### new_recording
```javascript
socket.on('new_recording', (data) => {
  console.log('تسجيل جديد:', data);
  // data: { recording_id, device_id, duration, filename }
});
```

#### new_screenshot
```javascript
socket.on('new_screenshot', (data) => {
  console.log('لقطة شاشة جديدة:', data);
  // data: { screenshot_id, device_id, filename, thumbnail_url }
});
```

#### system_alert

## 💡 أمثلة الاستخدام

### Python Example
```python
import requests
import json

# تسجيل الدخول
login_response = requests.post('http://localhost:5000/api/auth/login', 
    json={
        'username': 'admin',
        'password': 'admin123'
    }
)

token = login_response.json()['data']['token']
headers = {'Authorization': f'Bearer {token}'}

# الحصول على قائمة الأجهزة
devices_response = requests.get('http://localhost:5000/api/devices', 
    headers=headers
)

devices = devices_response.json()['data']['devices']
print(f'عدد الأجهزة: {len(devices)}')

# إرسال أمر لقطة شاشة
command_response = requests.post('http://localhost:5000/api/remote/command',
    headers=headers,
    json={
        'device_id': devices[0]['device_id'],
        'command': 'screenshot',
        'parameters': {'quality': 'high'}
    }
)

command_id = command_response.json()['data']['command_id']
print(f'تم إرسال الأمر: {command_id}')
```

### JavaScript Example
```javascript
// تسجيل الدخول
async function login() {
    const response = await fetch('/api/auth/login', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({
            username: 'admin',
            password: 'admin123'
        })
    });
    
    const data = await response.json();
    localStorage.setItem('token', data.data.token);
    return data.data.token;
}

async function getDevices() {
    const token = localStorage.getItem('token');
    const response = await fetch('/api/devices', {
        headers: {
            'Authorization': `Bearer ${token}`
        }
    });
    
    const data = await response.json();
    return data.data.devices;
}
```
