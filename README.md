## 🚀 **التثبيت السريع - Quick Installation**

### 1. استنساخ المشروع - Clone Repository:
```bash
git clone https://github.com/AlmutlabFadi/monitoring-improvements.git
cd monitoring-improvements
```

### 2. إعداد البيئة - Setup Environment:
```bash
# إنشاء البيئة الافتراضية - Create virtual environment
python -m venv venv

# تفعيل البيئة - Activate environment
# Linux/macOS:
source venv/bin/activate
# Windows:
venv\Scripts\activate
```

### 3. تثبيت المتطلبات - Install Requirements:
```bash
pip install --upgrade pip
pip install -r .requirements_unified.txt
```

### 4. إعداد الإعدادات - Configure Settings:
```bash
cp .env.example .env
# قم بتحرير ملف .env وإضافة المفاتيح المطلوبة
# Edit .env file and add required keys
```

### 5. تشغيل النظام - Run System:
```bash
python .ULTIMATE_SYSTEM_INTEGRATOR.py
```

## 🔧 **استكشاف الأخطاء - Troubleshooting**

### مشاكل شائعة:

#### 1. خطأ في تثبيت المتطلبات:
```bash
pip install --upgrade pip wheel
pip install -r .requirements_unified.txt --force-reinstall
```

#### 2. مشاكل المنافذ:
```bash
# التحقق من المنافذ المستخدمة
netstat -tulpn | grep :5000
sudo kill -9 $(lsof -t -i:5000)
```

#### 3. مشاكل الصلاحيات:
```bash
chmod +x *.py
```
