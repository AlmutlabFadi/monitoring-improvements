## 💻 متطلبات النظام

### الحد الأدنى للمتطلبات

#### للخادم الخلفي
- **نظام التشغيل**: Ubuntu 18.04+, CentOS 7+, Windows Server 2016+
- **المعالج**: 2 cores, 2.0 GHz
- **الذاكرة**: 4 GB RAM
- **التخزين**: 50 GB SSD
- **الشبكة**: اتصال إنترنت مستقر 10 Mbps+

#### للتطبيق المكتبي
- **نظام التشغيل**: Windows 10+, macOS 10.14+, Ubuntu 18.04+
- **المعالج**: 1 core, 1.5 GHz
- **الذاكرة**: 2 GB RAM
- **التخزين**: 1 GB مساحة فارغة
- **الشاشة**: دقة 1024x768 أو أعلى

### المتطلبات الموصى بها

#### للإنتاج
- **المعالج**: 4+ cores, 3.0 GHz
- **الذاكرة**: 16 GB RAM
- **التخزين**: 500 GB NVMe SSD
- **الشبكة**: اتصال مخصص 100 Mbps+
- **النسخ الاحتياطي**: تخزين خارجي للنسخ الاحتياطية

### البرامج المطلوبة

#### الأساسية
- **Python**: 3.8+ مع pip
- **Node.js**: 16+ مع npm
- **Git**: لإدارة الإصدارات
- **SSL Certificate**: للأمان في الإنتاج

#### قواعد البيانات (اختيارية للإنتاج)
- **PostgreSQL**: 12+ (موصى به للإنتاج)
- **MySQL**: 8.0+ (بديل)
- **Redis**: للتخزين المؤقت

#### خوادم الويب (للإنتاج)
- **Nginx**: 1.18+ (موصى به)
- **Apache**: 2.4+ (بديل)

```nginx
server {
    listen 80;
    server_name your-domain.com www.your-domain.com;
    
    # إعادة توجيه HTTP إلى HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com www.your-domain.com;
    
    # شهادات SSL
    ssl_certificate /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;
    
    # إعدادات SSL
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-RSA-AES256-GCM-SHA512:DHE-RSA-AES256-GCM-SHA512:ECDHE-RSA-AES256-GCM-SHA384:DHE-RSA-AES256-GCM-SHA384;
    ssl_prefer_server_ciphers off;
    ssl_session_cache shared:SSL:10m;
    ssl_session_timeout 10m;
    
    # إعدادات الأمان
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
    add_header X-Frame-Options DENY always;
    add_header X-Content-Type-Options nosniff always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
    
    # حد حجم الملفات
    client_max_body_size 500M;
    
    # الملفات الثابتة
    location /static/ {
        alias /var/www/monitoring-app/static/;
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
    
    location /uploads/ {
        alias /var/www/monitoring-app/uploads/;
        expires 1d;
        add_header Cache-Control "private";
    }
    
    # API والتطبيق الخلفي
    location /api/ {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300;
        proxy_connect_timeout 300;
        proxy_send_timeout 300;
    }
    
    # WebSocket
    location /socket.io/ {
        proxy_pass http://127.0.0.1:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    
    # لوحة التحكم الويب
    location / {
        root /var/www/monitoring-app/web-dashboard/build;
        try_files $uri $uri/ /index.html;
        expires 1d;
        add_header Cache-Control "public";
    }
}
```

### إعدادات النسخ الاحتياطي

#### نسخ احتياطي تلقائي
```bash
# إنشاء سكريبت النسخ الاحتياطي
sudo nano /usr/local/bin/backup-monitoring-app.sh
```

```bash
#!/bin/bash

BACKUP_DIR="/var/backups/monitoring-app"
DATE=$(date +%Y%m%d_%H%M%S)
DB_NAME="monitoring_db"
DB_USER="monitoring-app"

# إنشاء مجلد النسخ الاحتياطية
mkdir -p $BACKUP_DIR

# نسخ احتياطي لقاعدة البيانات
pg_dump -U $DB_USER -h localhost $DB_NAME | gzip > $BACKUP_DIR/db_backup_$DATE.sql.gz

# نسخ احتياطي للملفات
tar -czf $BACKUP_DIR/files_backup_$DATE.tar.gz /var/www/monitoring-app/uploads/

# حذف النسخ القديمة (أكثر من 30 يوم)
find $BACKUP_DIR -name "*.gz" -mtime +30 -delete

echo "Backup completed: $DATE"
```

#### iptables (متقدم)
```bash
# حفظ القواعد الحالية
sudo iptables-save > /tmp/iptables.backup

# إعداد قواعد جديدة
sudo iptables -F
sudo iptables -P INPUT DROP
sudo iptables -P FORWARD DROP
sudo iptables -P OUTPUT ACCEPT

# السماح بالاتصالات المحلية
sudo iptables -A INPUT -i lo -j ACCEPT

# السماح بالاتصالات المؤسسة
sudo iptables -A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT

# السماح بـ SSH
sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT

# السماح بـ HTTP/HTTPS
sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# حفظ القواعد
sudo iptables-save > /etc/iptables/rules.v4
```

#### سكريبت مراقبة الصحة
```bash
# إنشاء سكريبت المراقبة
sudo nano /usr/local/bin/health-check.sh
```

```bash
#!/bin/bash

API_URL="https://your-domain.com/api/health"
LOG_FILE="/var/log/monitoring-app/health.log"

# فحص حالة API
response=$(curl -s -o /dev/null -w "%{http_code}" $API_URL)

if [ $response -eq 200 ]; then
    echo "$(date): API is healthy" >> $LOG_FILE
else
    echo "$(date): API is down (HTTP $response)" >> $LOG_FILE
    # إرسال تنبيه
    echo "Monitoring App API is down" | mail -s "Alert: API Down" admin@your-domain.com
fi

# فحص استخدام القرص
disk_usage=$(df / | awk 'NR==2 {print $5}' | sed 's/%//')
if [ $disk_usage -gt 85 ]; then
    echo "$(date): High disk usage: $disk_usage%" >> $LOG_FILE
    echo "Disk usage is at $disk_usage%" | mail -s "Alert: High Disk Usage" admin@your-domain.com
fi

# فحص استخدام الذاكرة
memory_usage=$(free | awk 'NR==2{printf "%.0f", $3*100/$2}')
if [ $memory_usage -gt 90 ]; then
    echo "$(date): High memory usage: $memory_usage%" >> $LOG_FILE
    echo "Memory usage is at $memory_usage%" | mail -s "Alert: High Memory Usage" admin@your-domain.com
fi
```

## 💾 النسخ الاحتياطي والاستعادة

### استراتيجية النسخ الاحتياطي

#### النسخ الاحتياطي الكامل
```bash
#!/bin/bash
# full-backup.sh

BACKUP_ROOT="/var/backups/monitoring-app"
DATE=$(date +%Y%m%d_%H%M%S)
FULL_BACKUP_DIR="$BACKUP_ROOT/full_$DATE"

mkdir -p $FULL_BACKUP_DIR

# نسخ احتياطي لقاعدة البيانات
pg_dump -U monitoring-app -h localhost monitoring_db > $FULL_BACKUP_DIR/database.sql

# نسخ احتياطي للملفات
cp -r /var/www/monitoring-app/uploads $FULL_BACKUP_DIR/
cp -r /etc/monitoring-app $FULL_BACKUP_DIR/config

# نسخ احتياطي للكود
cp -r /home/monitoring-app/monitoring-system $FULL_BACKUP_DIR/source

# ضغط النسخة الاحتياطية
tar -czf $BACKUP_ROOT/full_backup_$DATE.tar.gz -C $BACKUP_ROOT full_$DATE
rm -rf $FULL_BACKUP_DIR

echo "Full backup completed: full_backup_$DATE.tar.gz"
```

#### النسخ الاحتياطي التزايدي
```bash
#!/bin/bash
# incremental-backup.sh

BACKUP_ROOT="/var/backups/monitoring-app"
DATE=$(date +%Y%m%d_%H%M%S)
LAST_BACKUP=$(find $BACKUP_ROOT -name "*.tar.gz" -type f -printf '%T@ %p\n' | sort -n | tail -1 | cut -d' ' -f2-)

# نسخ احتياطي للملفات المتغيرة فقط
find /var/www/monitoring-app/uploads -newer $LAST_BACKUP -type f | tar -czf $BACKUP_ROOT/incremental_$DATE.tar.gz -T -

echo "Incremental backup completed: incremental_$DATE.tar.gz"
```

### الاستعادة

#### استعادة قاعدة البيانات
```bash
#!/bin/bash
# restore-database.sh

BACKUP_FILE=$1

if [ -z "$BACKUP_FILE" ]; then
    echo "Usage: $0 <backup_file.sql>"
    exit 1
fi

# إيقاف التطبيق
systemctl stop monitoring-app

# إنشاء نسخة احتياطية من البيانات الحالية
pg_dump -U monitoring-app monitoring_db > /tmp/current_backup_$(date +%Y%m%d_%H%M%S).sql

# حذف قاعدة البيانات الحالية
dropdb -U monitoring-app monitoring_db

# إنشاء قاعدة بيانات جديدة
createdb -U monitoring-app monitoring_db

# استعادة البيانات
psql -U monitoring-app monitoring_db < $BACKUP_FILE

# إعادة تشغيل التطبيق
systemctl start monitoring-app

echo "Database restored from $BACKUP_FILE"
```

#### استعادة الملفات
```bash
#!/bin/bash
# restore-files.sh

BACKUP_FILE=$1
RESTORE_DIR="/var/www/monitoring-app"

if [ -z "$BACKUP_FILE" ]; then
    echo "Usage: $0 <backup_file.tar.gz>"

chown -R www-data:www-data $RESTORE_DIR/uploads

echo "Files restored from $BACKUP_FILE"
```
